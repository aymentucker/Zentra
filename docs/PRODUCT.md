# Zentra Product Foundation

## Positioning

Zentra is a focused system-care and storage-intelligence application for macOS. It is intended for everyday users while providing deeper value for developers and creators.

## Core areas

- Smart Care
- Cleanup
- Storage
- Duplicates
- Tidy Up
- Applications
- Performance
- Startup
- Developer / Creator cleanup
- Privacy and security insights

## UX principles

- Explain what will happen before destructive actions.
- Prefer reviewable recommendations over blind one-click deletion.
- Use Trash/recoverable workflows where appropriate.
- Keep advanced information available without overwhelming ordinary users.
- Never claim a scan or optimization happened when it did not.
- Treat Arabic and English as equal product experiences.

## M0 definition of done

M0 is complete when the project has a production-oriented SwiftUI foundation, reusable design tokens/components, navigation/app shell, custom icon foundation, localization, English LTR and Arabic RTL support, and a clean build/test baseline.
