# Zentra

Zentra is a native macOS system care, storage intelligence, and performance utility built with Swift and SwiftUI.

## Product direction

Zentra is designed around safe cleanup, storage visibility, application management, developer/creator cleanup, performance insights, and a focused Smart Care experience.

## Principles

- Native macOS experience
- Safety before deletion
- Privacy-first and local-first where possible
- Modular architecture
- English and Arabic from day one
- Full LTR and RTL support
- Custom visual identity and icon system
- No misleading or fake system actions

## Development

The stable branch is `main`. Development is performed on feature branches and merged through pull requests.
